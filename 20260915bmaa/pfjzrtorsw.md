# 丝瓜催乳汤怎么做更下奶？

> 更新时间：2026-09-15 (UTC+8)

用丝瓜催乳汤可以直接将丝瓜在水中煮，最好加入中药王不留行才会有效果，也可以在汤中加上一些排骨、粉丝之类的，能够很好的增强营养，起到催奶的功效，要注意让患者广泛的摄取营养，多吃一些高热量、高营养的食物，这样才能够使奶水尽快的生出来。

既然丝瓜下奶的功效这么好，下面就介绍几种丝瓜汤的做法：

**一、丝瓜猪蹄汤**

食材：200克丝瓜、200克豆腐、50克香菇、1个猪前蹄、盐、姜丝、葱段。

做法

- 1. 将猪蹄剃干净毛，用清水洗干净，用刀斩成小块；
- 2. 把豆腐放到盐水中浸泡10-15分钟，然后用清水清洗干净，也切成小块；
- 3. 将丝瓜削去外皮，用清水清洗干净，并切成薄片;将香菇切去老蒂，清水浸软之后，洗干净；
- 4. 把猪蹄放在锅中，加大约2500克清水，放在炉火上煎煮，煮到肉烂的时候，放入香菇、豆腐、丝瓜等，并加入盐、姜、葱，继续煮几分钟即可。

**二、丝瓜鸡蛋汤**

食材：丝瓜、鸡蛋、木耳

做法

- 1. 将丝瓜切块；
- 2. 丝瓜、木耳加水煲汤，至熟烂；
- 3. 将丝瓜削去外皮，用清水清洗干净，并切成薄片;将香菇切去老蒂，清水浸软之后，洗干净；
- 4. 打蛋花及油盐调味即可。

**三、丝瓜大虾汤**

食材：丝瓜、虾、葱、姜

做法

- 1. 丝瓜洗净，削去表皮，丝瓜肉切成片，葱姜切末；
- 2. 虾洗净，剪去虾须，去掉沙线；
- 3. 将丝瓜、虾、葱姜一起放入慢炖锅，加入水通电，炖熟即可。

当新妈妈出现乳腺炎症，哺乳期乳房有包块，乳汁分泌不畅时，中医会建议将丝瓜络放在高汤内炖煮，可以起到通调乳房气血、通乳和开胃化痰功效。
